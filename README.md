Ember Duel — a complete, original card game that plays offline in a desktop browser. You duel Vex, the Ember Warden, with a hand of elemental cards from four original suits (Ember, Tide, Thorn, Gale). Each card has a mana cost and an attack value; play it and it strikes the opponent for its attack. Both duelists start at 20 life, mana grows as the duel goes on, and the first life total to hit zero loses. Title screen, live table with both hands, readable cards, score and life totals, and win and loss screens are all in the game.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Click a card (or press 1–5) to play it, Space to start, P to pause. No network request is made; the game is static files under game/.
